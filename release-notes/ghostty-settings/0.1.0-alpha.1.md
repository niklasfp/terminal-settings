First alpha of **ghostty-settings**: a settings window for the [Ghostty](https://ghostty.org) terminal. Run it, and a settings page opens in your browser. Saving writes Ghostty's config and asks a running Ghostty to reload (on macOS; on Linux, press Ctrl+Shift+,).

- All Ghostty options, grouped and searchable, with Ghostty's own documentation.
- Every save is checked by Ghostty's own `+validate-config` first. Only the lines you change are touched, and comments are kept.
- Theme picker with previews of Ghostty's bundled themes, plus font and color pickers (including X11 color names), key-binding and palette editors.
- Light and dark mode.

**Downloads:** pick the file for your OS and CPU below (`osx-arm64`, `linux-x64`, `linux-arm64`). There's no Windows build, because Ghostty doesn't run on Windows. The binaries aren't signed. See the [README](https://github.com/niklasfp/terminal-settings#install) for the one-time step on macOS. `SHA256SUMS` lists checksums for every file.

This is an alpha, so expect rough edges. Please report issues.
