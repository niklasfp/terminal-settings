Alpha update of **ghostty-settings**.

- The sidebar now shows the app version and the commit it was built from, linked to GitHub.
- `ghostty-settings --version` prints the commit too, e.g. `ghostty-settings 0.1.0-alpha.3 (abc1234)`.

**Downloads:** same files as before; see the [README](https://github.com/niklasfp/terminal-settings#install) for which one to pick and the one-time steps for unsigned binaries. `SHA256SUMS` lists checksums for every file.

This is an alpha, so expect rough edges. Please report issues.
