Alpha update of **ghostty-settings**.

- **The native desktop app is now the only version.** The earlier browser-based `.NET` editor has been retired, and the native GPUI app introduced in `0.1.0-alpha.5` now ships under the main `ghostty-settings-<version>-<rid>` asset names (no `-gpui` prefix):
  - **Mac:** `ghostty-settings-0.1.0-alpha.6-osx-arm64.zip` (`Ghostty Settings.app`).
  - **Linux:** `ghostty-settings-0.1.0-alpha.6-linux-x64.tar.gz` and `…-linux-arm64.tar.gz`.
- **Action suggestions for key bindings:** typing an action in the `keybind` table now suggests matching Ghostty actions (`copy_to_clipboard`, `new_split`, `goto_tab`, `reload_config`, and so on) with prefix matches ranked first.
- **macOS Application Support config location:** on macOS, the editor now checks `~/Library/Application Support/com.mitchellh.ghostty/config.ghostty` (and `config`) before `~/.config/ghostty/`, skipping zero-byte files and matching Ghostty's own config selection.
- **Remembered appearance:** choosing System, Light, or Dark is now saved and restored the next time you open the app.

**Downloads:** see the [README](https://github.com/niklasfp/terminal-settings#install) for which file to pick and the one-time steps for unsigned apps. `SHA256SUMS` lists checksums for every file.
