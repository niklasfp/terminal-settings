Alpha update of **ghostty-settings**.

- **New file picker.** "Choose…" now opens a picker inside the settings page instead of the system's file dialog, the same on every platform. It shows shortcuts to your config folder, home, Desktop, Documents, Downloads, Pictures and Music (and your drives on Windows). It lists only files that fit the setting, and opens where the current file is, with that file selected. Use it for the custom shader, background image or working directory.
- On Windows, the old system dialog could open behind the browser. That can't happen any more.
- On Linux, "Choose…" no longer needs `zenity` or `kdialog`.
- "Choose…" buttons now line up with the text field next to them.

**Downloads:** see the [README](https://github.com/niklasfp/terminal-settings#install) for which file to pick and the one-time steps for unsigned binaries. `SHA256SUMS` lists checksums for every file.

This is an alpha, so expect rough edges. Please report issues.
