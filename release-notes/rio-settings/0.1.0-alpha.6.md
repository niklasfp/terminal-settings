Alpha update of **rio-settings**.

- **The native desktop app is now the only version.** The earlier browser-based `.NET` editor has been retired, and the native GPUI app introduced in `0.1.0-alpha.5` now ships under the main `rio-settings-<version>-<rid>` asset names (no `-gpui` prefix):
  - **Mac:** `rio-settings-0.1.0-alpha.6-osx-arm64.zip` (`Rio Settings.app`).
  - **Linux:** `rio-settings-0.1.0-alpha.6-linux-x64.tar.gz` and `…-linux-arm64.tar.gz`.
  - **Windows:** `rio-settings-0.1.0-alpha.6-win-x64.zip` and `…-win-arm64.zip`.
- **Remembered appearance:** choosing System, Light, or Dark is now saved and restored the next time you open the app.

**Downloads:** see the [README](https://github.com/niklasfp/terminal-settings#install) for which file to pick and the one-time steps for unsigned apps. `SHA256SUMS` lists checksums for every file.
