First alpha of **rio-settings**: a settings window for the [Rio](https://rioterm.com) terminal. Run it, and a settings page opens in your browser. Saving writes Rio's `config.toml`, and Rio reloads by itself.

- Every Rio option, grouped and searchable, with defaults and docs. Built from Rio's own source.
- Saves only the lines you change, keeps your comments, shows a diff first, and keeps a `.bak`.
- Color, font and theme pickers with previews. Themes you don't have yet are downloaded when you pick them.
- Per-platform overrides ("Applies to"), plus light and dark mode.

**Downloads:** pick the file for your OS and CPU below (`osx-arm64`, `linux-x64`, `linux-arm64`, `win-x64`, `win-arm64`). The binaries aren't signed. See the [README](https://github.com/niklasfp/terminal-settings#install) for the one-time steps on macOS and Windows. `SHA256SUMS` lists checksums for every file.

This is an alpha, so expect rough edges. Please report issues.
