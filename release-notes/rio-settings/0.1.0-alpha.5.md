Alpha update of **rio-settings**.

- **New: a native version to try.** Next to the usual downloads, this release has `rio-settings-gpui-…` files. It's the same editor, but as a native app with its own window instead of a page in your browser. It edits the same `config.toml` the same safe way: only the lines you change, a diff before saving, and a `.bak` backup.
  - **Mac:** `rio-settings-gpui-…-osx-arm64.zip` holds `Rio Settings.app`. Unzip it and drag it to Applications. It isn't notarized by Apple, so the first time macOS says it "could not verify" the app. Click **Done**, then open **System Settings → Privacy & Security**, scroll to Security and click **Open Anyway**. Or run `xattr -dr com.apple.quarantine "/Applications/Rio Settings.app"` once. (Right-click → Open no longer works on macOS 15 and later.)
  - **Linux:** `rio-settings-gpui-…-linux-x64.tar.gz` / `…-linux-arm64.tar.gz`.
  - **Windows:** `rio-settings-gpui-…-win-x64.zip` / `…-win-arm64.zip`.
- **What's new in the native version:**
  - Fonts and themes are searchable dropdowns that show each font in its own face and each theme with its colors. Themes not yet installed download when picked.
  - Path settings have their buttons inside the field: choose a file, show it in your file manager, or see a warning when it doesn't exist. You can also drop a file onto the field.
  - Each section shows how many of its settings your config sets, and those settings are marked "In your config".
  - It has keyboard shortcuts (and a menu bar on macOS), follows light/dark mode, and has its own app icon.
- The browser version is unchanged and still the main download.

**Downloads:** see the [README](https://github.com/niklasfp/terminal-settings#install) for which file to pick and the one-time steps for unsigned binaries. `SHA256SUMS` lists checksums for every file.

This is an alpha, and the native version is new, so expect rough edges. Please report issues.
