# AGENTS.md

Guidance for coding agents working in this repo. See [README.md](README.md) for what the apps do.

## Layout

- `gpui/`: the Rust Cargo workspace for both native GPUI apps. See [gpui/AGENTS.md](gpui/AGENTS.md)
  for workspace crate layout, GPUI rules, and gotchas.
  - `crates/settings-core`: terminal-agnostic core (`Schema`, `ConfigFormat`, `ConfigStore`, atomic
    writes, diffing, schema merge plumbing, value checks).
  - `crates/settings-ui`: shared GPUI window, controls, dropdowns, path fields, menus, and UI tests.
  - `crates/rio-config`, `crates/ghostty-config`: terminal-specific format, schema merge, value
    writers, validation, reload, and themes.
  - `apps/rio-settings`, `apps/ghostty-settings`: binary crates for each app.
  - `apps/settings-web`: the browser playground (wasm32, both apps, `?app=rio|ghostty`). Browser
    specifics stay at the edges: `settings_ui::playground::Playground` hooks and
    `cfg(target_family = "wasm")` in this crate, `run_web`, and Rio's theme download.
  - `vendor/gpui-kit`: gpui-kit with gpui-pre's `multithreaded` default off (see `VENDORED.md`).
- `schema/<terminal>/<terminal>-source.json`: **generated** by `node tools/<terminal>/update-schema.ts`
  (automatically proposed as a draft PR by `.github/workflows/upstream-schema.yml`). Never hand-edit it.
  `schema/ghostty/ghostty-themes.json` (the themes Ghostty ships, for the browser playground) is
  generated by the same script.
- `schema/<terminal>/<terminal>-overlay.json`: the hand-written layer (groups, ranges, widgets,
  labels where needed).
- `tools/`: TypeScript scripts for regenerating schemas (`tools/rio/`, `tools/ghostty/`,
  `tools/upstream-schema.ts`), packaging macOS bundles (`tools/gpui/package-macos.ts`), generating
  icons (`tools/gpui/make-icons.ts`), and taking README screenshots (`tools/screenshots.ts`).
- `brand/`: terminal logos and app icons.

## Standing rules

- The two apps ship separately. Nothing terminal-specific belongs in `settings-core` or
  `settings-ui`. Put it in the app's `AppDefinition` / `ConfigFormat` crate or in its overlay (e.g.
  `app.themeLocksColors`, `app.scopes`).
- Edits must preserve everything they don't touch:
  - Rio: splice text into the exact TOML syntax span (`toml_edit` raw spans) and re-parse after
    every edit.
  - Ghostty: replace whole `key = value` lines (the last one for scalars, all of them for
    repeatable keys, in place).
  - Never re-serialise a whole file.
- Rio: only emit TOML 1.0 syntax (`toml_edit` parses 1.1, matching current Rio). So no multi-line
  inline tables, and no `\e` escape (use `\u001B`).
- Ghostty: never trim values when writing (`selection-word-chars` starts with a space), and quote
  values with leading or trailing whitespace. Every save must pass Ghostty's `+validate-config`.
  The AppleScript reload must never launch Ghostty.
- Writes go through `settings_core::store::write_atomically`, which resolves symlinks first, so a
  symlinked config is never replaced by a regular file.
- New options: describe them in the overlay. Don't special-case keys in Rust. Widgets are picked by
  `type`. A new widget type means updating `SettingType` in `settings-core`, each app's value writer,
  and `create_control` / `on_input` / `sync` / `render_control` in
  `gpui/crates/settings-ui/src/controls.rs`.
- Schemas track released terminal versions (`--rio vX.Y.Z` pins `tools/rio/schema-dump/Cargo.toml`
  to that tag and records `rioVersion` in `rio-source.json`; Ghostty records `ghosttyVersion` and
  `configZigRef`). `.github/workflows/upstream-schema.yml` runs nightly in a read-only job, runs the
  config crate tests, and opens or updates a draft PR on `schema/<target>` (using a GitHub App token
  from `APP_ID` + `APP_PRIVATE_KEY` or `SCHEMA_BOT_TOKEN` so `ci.yml` runs on the PR, with signed
  commits via GraphQL `createCommitOnBranch`).
- Scripts are TypeScript run with Node's native type stripping (`node file.ts`). No Python,
  no tsx.

## Commands

```sh
cargo test --manifest-path gpui/Cargo.toml --workspace --locked
cargo clippy --manifest-path gpui/Cargo.toml --workspace --all-targets --locked -- -D warnings
node tools/gpui/package-macos.ts
node tools/rio/update-schema.ts [--rio v0.5.29]
node tools/rio/update-themes.ts [--commit <sha>]
node tools/ghostty/update-schema.ts
```
